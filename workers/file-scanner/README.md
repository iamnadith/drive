# File Scanner

A durable Cloudflare Worker for R2 inventory and migration verification. Its own minutely cron is configured in `wrangler.jsonc`; it runs independently of dashboard traffic and claims only already-persisted scan work. Queue continuations drain active work between cron ticks. Each cron/queue run claims one task using PostgreSQL row locks and leases. This Free-tier-safe concurrency preserves single-task ownership and idempotent page commits without multiplying database connections. Each task adaptively processes 50 to 250 R2 objects per page and atomically persists object rows, exact counters, and the opaque continuation cursor in PostgreSQL. If an invocation ends, the next queue or cron invocation resumes from that committed cursor. Only after the complete source inventory is committed does the Migration Orchestrator materialize one-file jobs and start migration workers. After migration, File Scanner scans the destination and compares the completed inventory; Migration Orchestrator owns lifecycle decisions and completion. Opening a dashboard page never starts a scan.

Deploy with `PANEL_URL` and `FILE_SCANNER_SECRET` build variables. The deploy script verifies Wrangler authentication, creates the continuation queue and dead-letter queue when missing, and injects the database configuration. This Worker only inventories and verifies files. Migration lifecycle, account activation, bucket settings, and worker dispatch remain in the Migration Orchestrator.
