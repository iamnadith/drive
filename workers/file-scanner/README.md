# File Scanner

A durable Cloudflare Worker for R2 inventory and migration verification. The Migration Orchestrator creates scan work; the scanner's minute cron is a recovery/continuation trigger that only claims already-persisted tasks. Queue continuations drain active scans between cron ticks. File Scanner processes up to 1,000 R2 objects per page, atomically persists object rows, exact counters, and the opaque continuation cursor in PostgreSQL. Only after the complete source inventory is committed does the Migration Orchestrator materialize one-file jobs and start migration workers. After migration, File Scanner scans the destination and compares the completed inventory; Migration Orchestrator owns lifecycle decisions and completion. Opening a dashboard page never starts a scan.

Deploy with `PANEL_URL` and `FILE_SCANNER_SECRET` build variables. The deploy script verifies Wrangler authentication, creates the continuation queue and dead-letter queue when missing, and injects the database configuration. This Worker only inventories and verifies files. Migration lifecycle, account activation, bucket settings, and worker dispatch remain in the Migration Orchestrator.
